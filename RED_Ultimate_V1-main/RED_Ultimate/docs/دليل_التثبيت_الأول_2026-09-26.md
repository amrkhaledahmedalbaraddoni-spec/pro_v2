# 📱 دليل التثبيت الأول — RED Sovereign / YOUNES

> آخر تحديث: 2026-09-26 — لأول تجربة واقعية للتطبيق على جهاز حقيقي.

## 1) الملف الجاهز للتثبيت

```text
red-app/build/outputs/apk/release/app-release.apk   (219MB — موقّع، arm64-v8a)
```

- موقّع بشهادة الإصدار: `CN=RED Sovereign Release` (SHA-256: `973cbbca…1bda8`)
- احتفظ بمفتاح `red-app/signing/red-release.p12` وكلمة المرور في مكان آمن — **تحديثات المتجر تتطلب نفس المفتاح مدى الحياة**

## 2) التثبيت على جهاز أندرويد

### الطريقة الأولى (USB + adb — الأدق):
```bash
# فعّل «خيارات المطور» ثم «تصحيح USB» في هاتفك، ثم:
adb install -r red-app/build/outputs/apk/release/app-release.apk
```

### الطريقة الثانية (نقل مباشر):
1. انسخ `app-release.apk` إلى الهاتف (كابل/بلوتوث/سحابة)
2. اضغط الملف → اسمح بـ«تثبيت من مصدر غير معروف» → ثبّت
3. يتطلب أندرويد 8.0+ (minSdk 26) ومعمارية arm64 (كل الهواتف الحديثة)

## 3) أول تشغيل والاتصال بالسيرفر

1. افتح التطبيق → أنشئ حساباً جديداً (تُولَّد هوية Signal مشفرة محلياً)
2. في **إعدادات السيرفر**: أدخل عنوان خادمك (مثال: `http://192.168.1.10:8088`)
   - التطبيق يجرب تلقائياً عناوين شائعة عبر discovery إن تركته فارغاً
3. سجّل الدخول → ستُستكمل المزامنة تلقائياً (مفاتيح PreKey، جهات الاتصال، المحادثات)

## 4) سيرفر الاختبار السريع (Docker)

```bash
cd RED_Ultimate
docker compose up -d            # nginx + backend + postgres + redis + sfu
# السيرفر يستمع على 8088 (خارجي) — نفس ما يتوقعه التطبيق
```

## 5) قائمة فحص أول تجربة (نظام "الزجاج السيادي" + الميزات الجديدة)

| # | ما تختبره | المتوقع |
|---|---|---|
| 1 | أيقونة التطبيق | Y ذهبية على تدرج كحلي-زمردي (adaptive: يتكيف مع شكل المشغّل) |
| 2 | الشريط السفلي/العلوي + إدخال الشات | تأثير زجاج سيادي (بلور + حد مضيء) |
| 3 | إعدادات → الزجاج | 5 أنماط (تلقائي/منتظم/شفاف/بلوري/سيبراني) × 3 شدات × أداء × تباين |
| 4 | شات خاص → 📎 → استطلاع | إنشاء استطلاع (مجهول/متعدد/مؤقت) يصل للطرف الآخر كامل |
| 5 | مجموعة → استطلاع | نفس الحوار المتقدم + تصويت تفاعلي فوري |
| 6 | مكالمة فردية/جماعية | SDP محسّن (Opus+H264) — رفع نغمي نظيف |
| 7 | الوضع الفاتح والداكن | الزجاج يصحح نفسه تلقائياً في الفاتح |

## 6) إن واجهت مشكلة

| العرض | الحل |

| الزجاج ثقيل على جهاز قديم | إعدادات → الزجاج → الأداء: «متوازن» أو «اقتصادي» |
