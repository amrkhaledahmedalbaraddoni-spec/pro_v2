# 🏛️ RED Ultimate — المعمارية الشاملة وهندسة الشبكات والمنافذ

---

## 1. 🌐 نظرة عامة على المعمارية (System Architecture Overview)

منصة **RED Sovereign / RED Ultimate** هي منظومة اتصالات سيادية متكاملة وشاملة، تجمع بين:
1. **تطبيق الهاتف الذكي السيادي (`red-app`):** مبني بنظام Android Native الحديث (Kotlin + Jetpack Compose) بتصميم Cyberpunk/Sleek فاخر ومرونة عالية للتكيف مع جميع مقاسات الشاشات والأجهزة القابلة للطي.
2. **الباك إند السيادي (`backend-server`):** مبني بتقنيات Spring Boot 4.0.7 و Kotlin 2.3.21 و Java 21 مع معمارية موجهة بالأحداث (Event-Driven) وقفل موزع (Distributed Locks) عبر Redis للتشغيل المتزامن على خوادم متعددة (Clustering).
3. **لوحة التحكم الموحدة (`admin_dashboard`):** مبنية بـ React 19 و Vite و Tailwind CSS و `shadcn/ui` بدعم كامل للوضع الداكن المتقدم والتصميم الزجاجي (Glassmorphism).
4. **خادم وسائط الاتصال عالي الأداء (`media-sfu`):** مبني بـ Node.js و Mediasoup لإدارة مؤتمرات الصوت والفيديو بجودة فائقة (4K SFU) دون استهلاك نطاق ترددي مفرط.
5. **خادم المرحلات المشفر (`coturn`):** يوفر خدمات STUN/TURN لتجاوز جدران الحماية (NAT Traversal) مع تشفير كامل.
6. **موزع الإشعارات السيادية (`ntfy`):** تطبيق بروتوكول UnifiedPush الداخلي لتسليم إشعارات الإيقاظ الفوري للأجهزة دون الحاجة لخدمات Google أو أطراف خارجية.

## 3. 📱 إعدادات الاتصال في التطبيق ولوحة الإدارة (Client Connectivity)

### أ. تطبيق الأندرويد (`red-app`):
* **عنوان الخادم المعتمد (Default Base URL):** `http://<SERVER_IP>:8088`
* **الاتصال المحلي (Emulator):** `http://10.0.2.2:8088`
* **الاتصال عبر كابل USB مع ADB:**
  ```bash
  adb reverse tcp:8088 tcp:8088
  # ثم يوجه التطبيق إلى: http://127.0.0.1:8088
  ```
* **تلقي الإشعارات (UnifiedPush):**
  يوجه التطبيق موزع الإشعارات إلى `http://<SERVER_IP>:2586` للاستغناء التام عن Google Firebase Cloud Messaging (FCM).

### ب. لوحة الإدارة (`admin_dashboard`):
* **الدخول عبر المتصفح:** `http://<SERVER_IP>:8088`
* يتم تقديم واجهات الـ React تلقائياً عبر Nginx مع توجيه طلبات الـ API إلى `/api/` و `/v1/` داخلياً دون مشاكل CORS.

## 4. 🗄️ بنية قواعد البيانات ومحرك المزامنة (Database & Sync Engine)

1. **PostgreSQL 16 (البيانات السيادية والمزامنة):**
   * يدير المستخدمين، جهات الاتصال، الصلاحيات، وإعدادات الخصوصية.
   * يحتوي على **محرك المزامنة V66 (`device_sync_events`)**:
     * طابور تسلسلي غير متزامن يخزن جميع الأحداث (الرسائل، تعديلات المجموعات، حالات القراءة).
     * يتيح للأجهزة غير المتصلة سحب الأحداث الفائتة بالترتيب عند استعادة الاتصال (`GET /api/sync/events?lastSeq=...`).
2. **MongoDB 8 (تخزين الرسائل عالي السعة):**
   * تخزين الرسائل الفردية والجماعية المشفرة في `MessageDocument` و `GroupMessageDocument`.
   * فهرسة مركبة على `chatId`, `receiverId`, `timestamp` لضمان أداء قراءة فائق.
3. **Redis 7.4 (المراسلة اللحظية والمزامنة بين السيرفرات):**
   * شبكة `Redis Pub/Sub` عبر قنوات `red:calls:signals` و `red:messages:*` لربط السيرفرات المتعددة وتوصيل إشارات المكالمات والرسائل لحظياً.
   * قفل موزع (`ScheduledLockAspect`) لمنع تضارب الأعمال المجدولة.

## 5. 🚀 أوامر التشغيل والتحكم (Deployment & Runbooks)

### تشغيل المنظومة بالكامل عبر Docker:
```bash
# 1. نسخ وتعديل متغيرات البيئة
cp .env.example .env

# 2. تشغيل كافة الخدمات في الخلفية
docker compose up -d

# 3. التحقق من سلامة الحاويات
docker compose ps
./scripts/health-check.sh
```

### التشغيل المحلي للتطوير (Windows Dev Mode):
```cmd
:: تشغيل قواعد البيانات مع كشف المنافذ المحلية
run_red.bat
```
