# الخطة الرئيسية لتطوير RED Ultimate — 2026-09-26

مرجع النتائج المرصودة: [`AUDIT_STATE_2026-09-26.md`](AUDIT_STATE_2026-09-26.md).
هذه الخطة مبنية على فحص ساكن فعلي لهذه الجولة + تقرير `AUDIT_2026-09-26.md` (self-report).

## المبدأ الحاكم
لا تعديل قبل: **إثبات السلوك بالبناء/التشغيل** → **إصلاح أصغر قابل للمراجعة** → **إعادة التحقق**.
ممنوع: الحذف الأعمى، تعديل `.env` أو `secrets/`، إضعاف المصادقة/TLS/E2EE، أو كسر عقد عام/مخطط قاعدة بيانات دون توثيق.

## وحدة العمل
كل مرحلة = «حزمة» منفّذة، لها: نطاق ملفات، معيار قبول بأمر ونتيجة، ومخرَج موثّق. تُنفَّذ حزمة واحدة كاتبة في آنٍ واحد (كتابة واحدة على المستودع) لمنع التعارض، مع إمكانية فحص موازٍ للقراءة فقط.

## المرحلة 0 — خط أساس مُتحقَّق منه (إلزامية قبل أي شيء)
**النطاق:** لا تعديلات. تشغيل وقياس فقط.
**المهام:**
- `admin_dashboard`: `npx tsc --noEmit` + `npm run build` → تسجيل الحالة والزمن.
- `backend-server`: `./gradlew :bootJar -x test` ثم `test` → عدد الناجح/الفاشل.
- `red-app`: `./gradlew :app:compileDebugKotlin` + `testDebugUnitTest`.
- `docker compose up -d` → فحص `/health` عبر nginx (8088) وحالة كل حاوية، وآخر إصدار Flyway فعلي.
**معيار القبول:** أرقام فعلية مكتوبة في `docs/BASELINE_2026-09-26.md` (بدل الاعتماد على الادعاءات).
**سبب الأولوية:** إن لم نثبّت الخط الأساس، كل «تحسين» لاحق غير قابل للتحقق.

## المرحلة 1 — لوحة الأدمن (نظافة + اكتمال)
**النطاق:** `admin_dashboard/src/**`, `admin_dashboard/*.conf`, `vite.config.ts`.
1. حسم الـ 11 وحدة يتيمة: مقارنة كل زوج مكرّر (`AuditLog`/`AuditLogPage`, `Backups`/`BackupsPage`, `Settings`/`SettingsPage`) واختيار المعتمد، ثم **ربط أو إزالة** — لا حذف بلا مقرار.
2. إضافة مسارات/تنقّل لما هو مفيد وغير مكرر: `security/{RolesPage,M SessionsPage,MFAPage,SSOPage,ApiKeysPage}`, `system/{CachePage,ConfigPage,MigrationsPage}`.
3. توحيد `Security` ↔ `SecurityCenter` ↔ `pages/security/*` في تجربة واحدة غير مكرّرة.
4. RTL كامل + `i18n` بلا نصوص صلبة + تباين ألوان (light/dark) + استجابة كل الشاشات.
**معيار القبول:** `npm run build` ناجح + جرد يثبت أن **لا صفحة يتيمة** ولا مسار بلا مدخل.

## المرحلة 2 — التطبيق (الأولوية القصوى للمستخدم)
**النطاق:** `red-app/src/main/java/com/red/sovereign/**`.
1. إكمال الميزات المرصودة ناقصة: `LiveKitBridge` (تكامل فعلي أو تعطيل صريح موثّق)، `GroupCrypto` MLS، بحث القنوات، `MessageRetryWorker`.
2. توحيد نظام الثيمات: `ui/theme/*` (`RedTheme`, `SovereignThemeSystem`, `CustomThemeCreator`, `ParallaxWallpaper`) → مجموعة ألوان واحدة حديثة + أوضاع فاتح/داكن/تلقائي، بلا «تهريج أو ظلام».
3. الشاشات المستهدفة واحدة واحدة: الدردشات، الخاصة، طلبات الصداقة، المجموعات، الحالات، المنشورات/التغريدات، الإعدادات، والمكالمات (كل نوع: صوت/فيديو/جماعي/بث/مؤجّل).
4. أزرار/حركات/أيقونات + دعم كل أحجام الشاشات و`AdaptiveLayoutUtils`.
**معيار القبول:** `compileDebugKotlin` + `testDebugUnitTest` ناجحان، وتحقق يدوي على محاكي لكل شاشة معدّلة.
